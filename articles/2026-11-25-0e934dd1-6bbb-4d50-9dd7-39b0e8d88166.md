# 直播流主题切换只改 CSS 变量不动结构

<!-- content-workspace-job:0e934dd1-6bbb-4d50-9dd7-39b0e8d88166 -->

## 问题场景

直播流后台要支持深浅两套主题，原先每个组件都写死了颜色，改一次要动几十个文件。

## 实现步骤

在根选择器上定义颜色变量，组件样式一律引用变量而不是字面值。

```css
:root {
  --bg: #ffffff;
  --fg: #1f2328;
  --line: #d8dee4;
}
:root[data-theme="dark"] {
  --bg: #16181d;
  --fg: #e6edf3;
  --line: #30363d;
}
```

切换主题时只改根节点的类名，由类名覆盖变量取值。

```javascript
.card {
  background: var(--bg);
  color: var(--fg);
  border: 1px solid var(--line);
  padding: 12px 16px;
}
```

把选择结果写入本地存储，刷新后先读回再渲染，避免闪白。

```javascript
const root = document.documentElement;
function apply(mode) {
  root.dataset.theme = mode;
  localStorage.setItem('stream-theme', mode);
}
```

## 注意事项

变量要定义在包含所有组件的作用域上，写在组件内部无法被全局覆盖；内联样式优先级更高，会盖掉变量。

遇到复杂链路时，优先保证失败时能快速定位原因，确认指标平稳后再逐步放开。

如果数据量继续增长，优先用工具把现状量化出来再动手，让容量规划更有依据。

从成本角度看，应当限定作用范围避免影响其他业务，使整体改动风险可控。
