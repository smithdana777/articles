# 用唯一索引兜住报表表的重复写入

<!-- content-workspace-job:c42e5a27-0c9a-4a88-8592-b82a0b420196 -->

## 问题场景

报表表的写入先查后插，两个并发请求同时查到不存在，于是各插了一条。业务侧统计翻倍，清理时又不敢确定哪条该留。

## 实现步骤

在业务唯一键上建唯一索引，让数据库来保证不重复。

```sql
ALTER TABLE reports ADD UNIQUE KEY uk_rows (rows);
```

写入改成先尝试插入，冲突时按业务决定忽略还是更新。

```sql
INSERT INTO reports (id, rows) VALUES (1, 5000)
ON DUPLICATE KEY UPDATE rows = VALUES(rows);
```

确认索引真的生效，冲突时应当报 1062 而不是静默成功。

```sql
SELECT COUNT(*) FROM reports WHERE rows = 100;
SHOW INDEX FROM reports WHERE Key_name = 'uk_rows';
```
